# 北九州高専 学内デジタルマップ(試作)

学内デジタルマップ制作コンペ応募チームの開発リポジトリです。

## ファイル
- `index.html` — ルート検索(メイン)。出発地・行き先を選ぶと道順が表示される。
- `map.html` — 施設検索のみの地図(初期の試作)。
- `demo.html` — 架空キャンパスでの機能デモ(QR現在地・行事案内・運用更新のサンプル)。

## 使い方(ローカルで試す)
1. このリポジトリをダウンロード、または `git clone` する。
2. `index.html` をブラウザで直接開く(サーバー不要)。

## GitHub Pagesで公開する
1. リポジトリの Settings → Pages で、Branch を `main` / `/ (root)` に設定する。
2. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。
3. `index.html` がトップページとして開かれる。

## データの更新
地図・経路データは `index.html` 内の `FAC` ・ `HUBS` ・ `DATA`(ブラウザのlocalStorage)にある。
「道のデータを直す」タブで足した壁・道・入口は、JSONとして書き出して、このコードに反映できる(手順は本体のコメント参照、今後スプレッドシート連携に置き換え予定)。

## 出典
北九州高専「学内配置図」(学校公式サイトのPDF)をもとに作成。校内での利用・公開前に、学校へ使用の確認をすること。
